ESTE REPOSITÓRIO

C e C++ são tecnologias de desevnolvimento computacional construídas nos anos 70 e 80, e que até hoje se mantém como pilares de manutenção de outras tecnologias. O fundamento dessas linguagens é de fácil aprendizagem, apesar de serem taxada como 'montanhas íngremes' por muitos iniciantes. No entanto o conhecimento de arquitetura computacional e teorias de matemática façam jus para que essa facilidade ocorra, o perfil do jovem programador precisa estimar conhecimentos além tecnológicos.

Neste repositório, todo código C está compilado em C com extensão C e seguindo regras do C99 com premissas e privação de facilidades que o compilador moderno garante. Em C escrever um bom código depende inteiramente da experiência do engenheiro. Em C++ a praticidade de compiladores, na versão C23 permite é uma melhor garantia de produção, ainda que C++ exija muita base para ter um total controle dos efeitos de cada rotina.

Os graus de complexidade, são divididos em pastas do BÁSICO \ AVANÇADO \ SISTEMAS. E dentro delas o HPP e H para definir códigos de cabeçalho. Sempre indicados nos comentários desses qual pertence a qual.

BÁSICOS - São os fundamentos da linguagem. Códigos essencialmente simples com tamanhos reduzidos e com características de legibilidade mais 'triviais'.
AVANÇADOS - São tópicos que exijam algum nível conceitual como O POO (Programação Orientada a Objetos e Gerenciamento de Memória)
SISTEMAS - Envolve completo conhecimento sobre os fundamentos e POO para elaborar sistemas que passam por GAMES \ DATABASES \ SOFTWARES CORPORATIVOS
